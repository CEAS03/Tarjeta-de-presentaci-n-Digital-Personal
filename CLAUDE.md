carpeta, y lee los documentos que enumera. No hace falta consultar el vault.

además se paga en tokens cada sesión.

## Lo único propio de Claude Code

Mi papel en este proyecto es **planear**: investigo el código real y escribo el plan en
`PLAN-ACTIVO.md`, en esta misma carpeta. El archivo solo existe mientras haya un plan vigente;
Codex lo ejecuta y después se archiva.
